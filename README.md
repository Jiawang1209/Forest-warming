# Forest-warming

# Warming strengthens microbial diversity control of forest soil CO₂ emission

This repository contains the **analysis code and key datasets** associated with the manuscript:

> **Warming strengthens microbial diversity control of forest soil CO₂ emission**

The materials provided here are intended to support result reproducibility and methodological transparency.

## Contents
- Scripts used for data processing, statistical analyses, and figure generation  
- Key datasets underlying the main results of the study  

## Data availability
Some raw or extended datasets may not be publicly available due to data volume or project constraints.
